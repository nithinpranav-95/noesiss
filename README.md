# Noesis

Build only the frontend UI shell and Supabase foundation. Create the screens and navigation described in section 8, including Home, Debate Setup, Live Debate, Visual Games, Feedback Card, Framework Library, Lesson View, Progress Dashboard, onboarding, baseline assessment, training plan, and notification settings. Use placeholder data and clear placeholder functions for startDebate(), submitTurn(), and getFeedback(). Build the visual games as interactive UI prototypes with mock data. Connect Supabase and create the tables defined in section 6. Use Next.js-style components, Tailwind, shadcn/ui, and responsive layouts. Do not build voice functionality, Claude integration, scoring logic, AI prompts, or backend agent behavior.
